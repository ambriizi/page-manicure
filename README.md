# 💅 Manicure e Pedicure a Domicílio — Caroline Ambrizi

Landing page desenvolvida para divulgar e gerar agendamentos para o negócio de manicure e pedicure a domicílio da Caroline Ambrizi, atendendo o bairro Éden e região em Sorocaba/SP.

🔗 **Site no ar:** [page-manicure.vercel.app](https://page-manicure.vercel.app)

## 📋 Sobre o projeto

O objetivo da página é converter visitantes em agendamentos via WhatsApp, apresentando os serviços, a galeria de trabalhos e depoimentos de clientes de forma rápida e direta no celular — já que a maior parte do tráfego de negócios locais vem de mobile.

## ✨ Funcionalidades

- **Agendamento via WhatsApp** com mensagem pré-preenchida e personalizada para cada serviço (o cliente já chega no WhatsApp com o pedido pronto)
- **Botão flutuante de WhatsApp** fixo, sempre visível durante a navegação
- **Galeria/carrossel** de trabalhos com autoplay e navegação por setas
- **Seção de serviços** com preços e chamada de agendamento individual por serviço
- **Depoimentos de clientes** com avaliação em estrelas
- **SEO local otimizado**: meta tags Open Graph, Twitter Card, dados estruturados (Schema.org `NailSalon`) com endereço, área de atendimento e ofertas — ajuda o Google a entender e exibir melhor o negócio em buscas locais
- **Acessibilidade**: uso de `aria-label`, texto alternativo em todas as imagens e carregamento otimizado (`lazy loading`)
- Ícone e link direto para o Instagram do negócio

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3
- JavaScript puro (Vanilla JS)
- Google Fonts (Montserrat + Playfair Display)
- Dados estruturados Schema.org (JSON-LD)
